# Dashboard ร้านยาจำลอง — การจ่ายยาและยาคงคลัง

Dashboard แบบหน้าเว็บไฟล์เดียว (`index.html`) แสดงข้อมูลการจ่ายยา ยาคงคลัง การวางแผนสั่งซื้อ และบัญชียา 350 รายการ

> ข้อมูลเป็นข้อมูลจำลองเพื่อการเรียนเท่านั้น (รหัสผู้ป่วยเป็นรหัสแฝง)

## 4 มุมมอง
- **การจ่ายยา** — KPI, กราฟรายวัน/รายชั่วโมง, สัญญาณที่ควรตรวจสอบ
- **Drug Overview** — ภาพรวมบัญชียา แยกตามหมวด / ATC / รูปแบบยา
- **Inventory Planning** — ปรับ lead time, safety stock, วันครอบคลุม แล้วคำนวณรายการแนะนำสั่งซื้อ
- **Drug Explorer** — ค้นหา กรอง เรียง และดูรายละเอียดยาแต่ละตัว

## วิธีเปิดดู
- **ในเครื่อง:** ดับเบิลคลิก `index.html` (ไม่ต้องติดตั้งอะไร ไม่ต้องต่อเน็ต)
- **ออนไลน์ (GitHub Pages):** Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `(root)` → Save
  จากนั้นรอ 1–2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

## โครงสร้าง
```
index.html   ← ทั้งโค้ดและข้อมูลอยู่ในไฟล์นี้ไฟล์เดียว
README.md
.nojekyll    ← ให้ GitHub Pages เสิร์ฟไฟล์ตรง ๆ
```
